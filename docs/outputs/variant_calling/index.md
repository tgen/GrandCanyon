# Variant Calling

GrandCanyon provides constitutional and somatic variant callers, with results annotated by VEP.

- [Somatic Variant Callers](somatic/)
- [Constitutional Variant Callers](constitutional/)
- [Annotation](annotation/)

### Sequencing Data Support

GrandCanyon supports variant calling across multiple sequencing technologies:

- **Short-read (Illumina)**: Full support for all SNV/indel and SV callers.
- **Long-read (PacBio HiFi / ONT)**: Specialized callers for improved detection of structural variants and complex rearrangements.
