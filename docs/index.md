**GrandCanyon** is a jetstream workflow that supports the analysis of human sequencing
samples against the GRCh38 reference genome using ensembl version 113 gene
models. The workflow is designed to support project level analysis that can
include one or multiple types of data. Though not required the expectation is a
project contains data from a single individual thus centralizing all data types
in a standardized output structure. The workflow template supports a diverse
array of analysis methods required to analyze DNA and RNA data.
Based on standardized variables it also supports integrated analysis between
data types. For some processes multiple options are provided that can be
individually enabled or disabled by configuration parameters. Like all
[JetStream](https://github.com/tgen/jetstream) workflows developed at TGen this
workflow is designed to facilitate our dynamic and time sensitive analysis
needs while ensuring compute and storage resources are used efficiently. The
primary input is a JSON file, that for most internal users will be generated by
the TGen LIMS.

## What GrandCanyon Does

- **Short-read (Illumina) support** - DNA and RNA analysis from standard paired-end FASTQs:
  alignment with BWA-MEM2 (or MiniBWA / VG Giraffe for pangenomes), constitutional, somatic,
  and tumor-only SNV/indel calling, structural variants, copy number, and VEP annotation; RNA
  alignment and gene counts with STAR, Salmon quantification, and fusion detection with STAR-Fusion.
- **Long-read (PacBio HiFi/Kinnex, Oxford Nanopore) support** - alt-aware alignment with Minimap2,
  long-read optimized SNV/indel callers (DeepVariant Pangenome, Clair3, ClairS), structural
  variant callers (Sniffles, cuteSV, PBSV, Dysgu, Savana, Severus, tRGT), copy-number tools
  (HiFiCNV), methylation analysis (ModKit, RASTair, methbat), and isoform discovery/quantification
  (IsoSeq, Flair, IsoQuant, Oarfish, SQANTI3).
- **Integrated DNA/RNA analysis** - shared project-level pairing via `dnaRnaMergeKey` with a
  standardized output layout across data types.
